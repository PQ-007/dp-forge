# engine/ — тоглоомын суурь блокууд (багш)

Улирлын турш дахин ашиглагдах "барилгын блокууд" энд нэмэгдэнэ. Одоогоор хоосон, **3-р долоо хоногоос** эхэлнэ.

| Долоо хоног | Блок | Юу хийдэг |
|---|---|---|
| 3 | `world/` | Tile grid, мөргөлдөөн (AABB) |
| 4 | `save/` | Хадгалах / ачаалах |
| 5–7 | `ai/` | State machine, BFS / A*, behavior tree |
| 9–11 | `net/` | Сүлжээ: client / server |

**Энэ хавтсыг бүү засаарай.** Өөрийн тоглоомдоо `#include` хийж ашигла. Өөрчлөх хэрэгтэй бол файлыг `game/src/` руу хуулж аваад тэнд засна.
