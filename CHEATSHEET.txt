 2. BUILD БА АЖИЛЛУУЛАХ (VS Code, CMake Tools)
    Ctrl+Shift+P дараад командын нэрийг бич
--------------------------------------------------------------
  CMake: Select a Kit              compiler сонгох (нэг удаа)
  CMake: Configure                 = cmake -S . -B build
  CMake: Build              F7     = cmake --build build
  CMake: Set Launch/Debug Target   аль програмыг ажиллуулах вэ
                                   (game, w02_hello, w02_window …)
  CMake: Run Without Debugging     ажиллуулах  (Shift+F5)
                                   (өөрчлөлт байвал өөрөө build хийнэ)
  CMake: Debug              Ctrl+F5  debugger-тэй ажиллуулах
  CMake: Delete Cache and Reconfigure   эвдэрвэл эхнээс нь

  !! Баруун дээд булангийн ▶ (Run C/C++ File)-г БҮҮ дар.
  !! Терминалаас cmake бүү ажиллуул. Зөвхөн дээрх командууд.

--------------------------------------------------------------
 3. ӨДӨР БҮР: ӨӨРЧЛӨЛТӨӨ ХАДГАЛАХ (save point)
--------------------------------------------------------------
  git status                  юу өөрчлөгдсөнийг харах
  git diff                    яг ямар мөр өөрчлөгдсөнийг харах
  git add .                   бүх өөрчлөлтийг хайрцагт хийх
  git commit -m "тайлбар"     save хийх (юу хийснээ бич)
  git push                    GitHub дээрх өөрийн fork руу илгээх

  Жишээ:
    git add .
    git commit -m "Shift дарахад хурдан гүйдэг болгов"
    git push

--------------------------------------------------------------
 4. ДОЛОО ХОНОГ БҮР: БАГШИЙН ШИНЭ КОДЫГ ТАТАХ
--------------------------------------------------------------
  git pull --no-edit upstream main
  дараа нь F7 (build)

  Хичээлийн өмнө өөрийн өөрчлөлтөө commit хийсэн байх нь
  хамгийн найдвартай (3-р хэсэг).

--------------------------------------------------------------
 5. ТҮҮХ ХАРАХ
--------------------------------------------------------------
  git log --oneline           бүх save (commit)-ийн жагсаалт
  git log --oneline -5        сүүлийн 5
  git show                    сүүлийн commit юу өөрчилсөн бэ
  git tag                     долоо хоногийн шошгууд (week02 …)

--------------------------------------------------------------
 6. АЛДАА ЗАСАХ / БУЦААХ
--------------------------------------------------------------
  git restore game/src/player.cpp
        нэг файлыг сүүлийн commit-ийн байдал руу буцаах
        (commit хийгээгүй өөрчлөлт АЛГА БОЛНО!)

  git restore .
        БҮХ commit хийгээгүй өөрчлөлтийг буцаах (болгоомжтой!)

  git restore --staged .
        "git add" хийснээ буцаах (файл өөрчлөгдөхгүй)

  git commit --amend -m "шинэ тайлбар"
        сүүлийн commit-ийн тайлбарыг засах (push хийхээс ӨМНӨ)

--------------------------------------------------------------
 7. ӨМНӨХ ДОЛОО ХОНОГИЙН КОДЫГ ҮЗЭХ
--------------------------------------------------------------
  git switch --detach week02  кодыг week02 үеийн байдал руу
  git switch main             одоогийн хувилбар руугаа буцах

  Эхлээд өөрчлөлтөө commit хийсэн байх ёстой.

--------------------------------------------------------------
 8. ШАЛГАХ
--------------------------------------------------------------
  git remote -v
        origin   = ТАНЫ fork      (push энд явна)
        upstream = багшийн repo   (pull эндээс)

  git config --global --list  нэр, имэйл, тохиргоо

--------------------------------------------------------------
 9. CONFLICT ГАРВАЛ
--------------------------------------------------------------
  1) git status  ->  "both modified" гэсэн файлыг нээ
  2) Ийм хэсэг харагдана:
        <<<<<<< HEAD
        таны мөр
        =======
        багшийн мөр
        >>>>>>> ...
  3) Үлдээх мөрөө сонгоод <<<<<<<  =======  >>>>>>> мөрүүдийг устга
  4) git add .
  5) git commit -m "Conflict шийдэв"

  Мэдэхгүй бол:  git merge --abort  (pull-оос өмнөх байдал руу)
  Зөвхөн game/ дотор код бичвэл conflict гарахгүй!
